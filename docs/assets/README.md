# Assets docs

Living project asset lists and credits for Seedvale.

| File | Role |
|------|------|
| [MODELS.md](./MODELS.md) | **Required models** — backlog of models still needed or not yet wired |
| [SOUNDS.md](./SOUNDS.md) | **Required sounds** — backlog of SFX still needed or not yet wired |
| [CREDITS.md](./CREDITS.md) | Attribution for models already in the repo |
| `quaternius-*-license.txt` | Pack license copies |

Runtime files and per-file source notes:

- Models: `public/models/`
- Sounds: `public/sounds/` (+ [README](../../public/sounds/README.md) for filenames/sources)

## Development rule

When planning or implementing a feature, review both lists. If the feature needs a new model or sound, add a row during planning/implementation. If nothing new is needed, leave the lists unchanged.
