# Verified Blender / MPFB2 Procedures

This directory contains procedures that have been executed successfully in the target environment.

Each verified document must state:

- Blender version;
- MPFB2 version;
- Seedvale commit;
- exact procedure;
- expected result;
- actual result;
- limitations.

Do not place merely researched recipes here.

Initial verification targets:

1. Character generation.
2. Hair/beard asset attachment.
3. Medieval clothing attachment/fitting.
4. Game rig generation.
5. Mesh optimization and LOD generation.
6. GLB export and Seedvale import.
7. Deterministic batch generation.
