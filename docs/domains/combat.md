# Combat Domain Roadmap

**Status:** evolving target vision

## Purpose

Combat should be a shared world interaction used by the player, NPCs and fauna where appropriate, with clear consequences and reusable mechanics.

## Target state

- Damage, health, threat and death use shared concepts across agents.
- Player and NPC combat use the same underlying mechanics where practical.
- Animals participate through species-appropriate attack, defence, chase and flee behaviour.
- Combat decisions are influenced by needs, roles, relationships, equipment and circumstances.
- Combat can create persistent consequences for people, settlements and wildlife.
- Combat remains part of the living world rather than becoming a separate encounter system.

## Future evolution

1. Complete missing player combat interactions.
2. Deepen tactical and role-driven NPC behaviour.
3. Expand equipment and combat consequences.
4. Connect combat events to settlements, relationships and quests.

## Boundaries

Avoid building a separate combat AI stack for each actor type. Reuse shared simulation and combat contracts.
