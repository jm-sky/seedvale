# Plan: Mini-mapa (collapsible, z kierunkiem osady)

**Status:** `done`  
**Created:** 2026-08-07  
**Scope:** UI (gra), integracja z HUD

## Cel

Gracz potrzebuje szybkiego podglądu położenia względem osady (ekran przegląda się wszędzie). Mini-mapa w rogu ekranu powinna:
- Pokazać gracza (środek), osadę (marker+label), inne orientacyjne elementy (NPC, może fauna)
- Być minimalizowalna (collapse button) — zmienianie rozmiaru lub toggle `hidden`
- Wyświetlać kierunek do osady (strzałka/linia)
- Aktualizować się co klatkę (smooth follow)

## Stan obecny (dla kontekstu)

- HUD istniejący: `src/ui/createHud.ts` — czas gry, seed, hint (DOM + CSS `seedvale-hud__*`)
- Wzorzec UI: funkcje `create*` zwracają object z `root` + `dispose()` + metody do update'owania
- Brak mapy lub minimapy
- Wiadomo: `player.position`, `landmarks.settlement` (x, z), `npcAgents[]` w `createApp.ts`

## Zakres

### 1. Technologia: Canvas 2D
- Zdecydowanie Canvas 2D (nie Three.js ortho — mało kodu, szybkie, dosyć)
- Rozmiar: **200×200 px** (zmieniane w config jeśli potrzeba)
- Pozycja: **bottom-left**
- Zoom/scale: np. **1 unit gry = 2 px mapy** (zmienialne)

### 2. Zawartość mapy
| Element | Symbol | Kolor |
|---------|--------|-------|
| Gracz | ◆ (diamond) | biały / contrasting |
| Osada (building) | ■ (square) | żółty/brązowy |
| Kierunek do osady | → (strzałka) | żółty |
| NPC (opcjonalnie) | • (dot) | niebieski |

Gracz zawsze w centrum (jest obserwatorem).

### 3. Struktura kodu

```
src/ui/createMinimap.ts
  - type Minimap { root, canvas, update(playerPos, landmarks, npcAgents), toggle(), dispose() }
  - function createMinimap(parent, config): Minimap
  
  Kolej integracji:
  - src/app/createApp.ts :: loop() → minimap.update(player.position, landmarks, agents)
  - createApp.ts :: keyboard/ui hooks → minimap.toggle() na np. KeyM
```

### 4. Szczegóły implementacji

**Canvas setup:**
- Stwórz canvas element, append do `parent` (jak HUD)
- Context: `ctx = canvas.getContext('2d')`
- Device pixel ratio: `canvas.width = 200 * dpr`, `canvas.style.width = '200px'` (sharp na high-DPI)
- CSS: `position: absolute; top: 10px; right: 10px; border: 1px solid #ccc; background: #1a1a1a` (lub dark theme aware)

**Render każdy frame:**
- Wyczyść canvas: `ctx.fillStyle = ...; ctx.fillRect(0, 0, width, height)`
- Rysuj osadę: `fillRect(centerX + (settlement.x - player.x) * scale, ...)`
- Rysuj NPC: pętla, drawCircle per agent
- Rysuj kierunek: strzałka z gracza w stronę osady

**Collapsible:**
- Mini toggle button poza canvasem (np. `📍 [-]` = pokazana, `📍 [+]` = zwinięta)
- Stan: `collapsed: boolean`, toggle via button
- Gdy zwinięta: canvas i zawartość `hidden`, button zmienia label
- Alternatively: canvas zawsze widoczny, ale show/hide całego kontenera

**Update loop:**
```ts
function update(
  playerPos: Vector3,
  landmarks: SettlementLandmarks,
  npcAgents: NpcAgent[],
  observerPos: Vector3, // dla distanceFade jak HUD
): void
  // Walidacja: jeśli any landmark undefined, safe render (fallback)
  // Rysuj canvas
  // NPC: filtruj po distanceFade (jak label HUD) — nie pokazuj za daleko
```

### 5. Integracja w createApp.ts

```ts
// Po createHud
const minimap = createMinimap(uiParent)

// W głównym loop()
minimap.update(player.position, landmarks, agents, player.position)

// Keyboard: opcjonalnie toggle na KeyM
if (keyboard.isPressed('KeyM')) minimap.toggle()
```

## Implementacja (2026-08-07)

- `src/ui/createMinimap.ts` — Canvas 2D, wzorzec `create*` (root/update/toggle/dispose) jak `createHud.ts`
- CSS w `index.html`: `.seedvale-minimap`, `.seedvale-minimap__canvas`, `.seedvale-minimap__toggle`
- Integracja w `src/app/createApp.ts`: utworzony po `hud`, `minimap.update()` w głównym `tick()` (tylko gdy nie paused/dialog), `minimap.dispose()` w cleanup
- Brak keybindingu KeyM (był oznaczony "opcjonalnie" w planie) — toggle tylko przez button `[-]`/`[+]` w rogu mapy
- Mapa jest north-up (bez rotacji wg kierunku patrzenia gracza) — prostsze, zgodne z "smooth follow" przez samą translację
- `HALF_RANGE` (50 jednostek świata) — poza tym zasięgiem osada/NPC nie są rysowane wprost; dla osady rysowana jest strzałka kierunkowa zamiast markera
