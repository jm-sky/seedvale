## 6. Kryteria oceny

- **UX:** hierarchia, czytelność, discoverability, feedback, modalność, ile UI zasłania świat 3D, różnica mobile vs desktop.
- **Visual:** typografia, spacing, radius, kolory, kontrast, ikony, panele, z-index. Szukać bliźniaczych elementów o różnych stylach.
- **Mobile:** touch targets ≥44px, joystick vs E vs pauza vs minimapa, safe area, landscape A55, czy modale są używalne.
- **A11y (rozsądny zakres):** kontrast, focus, keyboard, informacja nie tylko kolorem. Semantyka HTML / aria — poza zakresem (skreślone w prompcie).
- **Vue/CSS:** duplikacja, hardcoded values, brakujące wspólne komponenty; co CSS (joystick, canvas minimapy, CSS2D), co Tailwind, czy cienka warstwa tokenów wystarczy.
- **shadcn-vue:** nie zakładać migracji wszystkiego. HUD/game chrome zostaje custom; panele/formularze mogą użyć primitive (Button, Dialog, Input). Nie drugi system obok store + facades.
