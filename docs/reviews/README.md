## After each run

1. Set status in this table and in the review file.
2. Record findings under **Findings** in the review file (severity + file refs).
3. Add or update rows in [issues/README.md](../issues/README.md) for actionable follow-ups.

When adding a new entry: create `YYYY-MM-DD-slug.md`, add a row here.
