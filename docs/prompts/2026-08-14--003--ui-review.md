# Seedvale — UI/UX Review

**Status:** `done` — raport: [review 007](../reviews/2026-08-14--007--ui-ux.md); plan implementacji: [105](../plans/2026-08-14--105--ui-ux-review.md) §8

Przeprowadź kompleksowy review UI/UX aplikacji Seedvale.

Seedvale jest browserową grą 3D zbudowaną w Vue.js (+Tailwind +ShadcnVue) + Three.js/WebGL2. UI działa zarówno na desktopie, jak i mobile.

Celem review nie jest tylko ocena CSS. Chcę ocenić całą warstwę interfejsu: UX, visual design, responsive behavior, komponenty Vue oraz organizację styli.

## 1. Zakres review

Przeanalizuj:

* wszystkie dostępne ekrany / views
* HUD
* przyciski i kontrolki
* interaction prompts
* inventory
* dialogi
* questy
* notifications
* panele / modale
* statusy gracza
* elementy związane z NPC
* elementy settlement
* elementy debug/dev UI, jeśli są widoczne dla gracza
* wszystkie istotne stany UI, np.:

  * normal
  * hover
  * active
  * disabled
  * selected
  * loading
  * empty
  * error
  * unavailable

Nie ograniczaj review do elementów, które są obecnie najbardziej widoczne.
Kluczowe są ekrany i kontrolki, a dialogi i interakcja ze światem mogą iść drugą fazą.

## 3. UX review

Oceń:

* hierarchię informacji
* czytelność
* discoverability
* feedback po akcjach gracza
* jednoznaczność przycisków i ikon
* ilość informacji jednocześnie prezentowanej graczowi
* modalność UI
* czy UI nie zasłania niepotrzebnie świata 3D
* czy najważniejsze informacje są dostępne szybko
* czy interakcje są intuicyjne
* czy mobile UX różni się odpowiednio od desktopowego

UI nie powinno sprawiać wrażenia klasycznej webowej aplikacji administracyjnej ani nadmiernie dominować nad żyjącym światem 3D, ale to nie jest priorytet - priorytet to UX.

## 8. Tailwind

Oceń obecną sytuację dotyczącą CSS i Tailwind.

Nie zakładaj z góry, że należy migrować wszystko do Tailwind.

Określ:

* co warto pozostawić jako CSS
* co warto przenieść do Tailwind
* gdzie Tailwind uprości kod
* gdzie może pogorszyć czytelność
* czy potrzebne są wspólne komponenty / utility classes
* czy warto wprowadzić niewielki design-token layer

Zaproponuj docelową strategię CSS/Tailwind dla projektu.

## 9. Seedvale-specific concerns

Sprawdź również, czy UI:

* nie wygląda zbyt "webowo"
* nie wygląda jak debug UI
* nie konkuruje wizualnie ze światem 3D
* zachowuje immersję
* dobrze komunikuje stan świata
* może skalować się wraz z rozwojem NPC, settlement, inventory, quests, economy i innych systemów
