# 038 — NPC labels and no-sound query param

**Status:** `todo`
**Created:** 2026-08-20
**Źródło:** playtest

1. **NPC labels/status bars**
   - Zwiększyć minimalną odległość wyświetlania NPC label oraz status barów (stamina, etc.).
   - Obecne ~5 m dla status barów i ~10–15 m dla labeli jest za blisko.
   - Zawęzić kąt względem kierunku kamery, aby UI nie pojawiało się dla NPC-ów znajdujących się mocno z boku.

2. **Dźwięk**
   - Dodać query param `?noSound=true`, który całkowicie wyłącza dźwięk w aplikacji.
