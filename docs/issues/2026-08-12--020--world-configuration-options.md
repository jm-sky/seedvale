# 020 — Expand world configuration options

**Status:** `done`

## Problem

The player-facing world configuration currently exposes only a small subset of the world settings.

## Expected behaviour

Add several useful world-generation options, starting with:

- settlement/home-village size.

The option should belong to world configuration, not player preferences or graphics settings, and should participate correctly in the existing world rebuild/new-world flow.

## Goal

Give the player meaningful control over the generated world while keeping world settings clearly separated from other configuration domains.
