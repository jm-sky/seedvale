# Medieval Village MegaKit — parked assets

Selected pieces from Quaternius **Medieval Village MegaKit (Standard / free)**, converted to optimized `.glb` (meshopt + WebP 512).

**Licencja:** CC0 1.0 — see [docs/assets/quaternius-medieval-village-megakit-license.txt](../../../docs/assets/quaternius-medieval-village-megakit-license.txt).

**Status:** parked / not wired into runtime yet. Load via existing `loadGltf` / `loadPropOrFallback` when needed.

**Uwaga:** Standard kit is mostly **modular** (walls/roofs/props), not pre-built houses. These 19 are the most useful standalone props + wall/fence segments for Seedvale settlements.
